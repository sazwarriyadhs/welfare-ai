# WELFARE AI - Drone Recommendation Guide

## Recommendation A: Enterprise Quadcopter

Reference model: DJI Matrice 4T.

Best suited for:
- Regular aerial livestock monitoring.
- Farm facility inspection.
- RGB and thermal image collection.
- Targeted monitoring operations.

Priority: 1.

## Recommendation B: Multispectral Drone

Reference model: DJI Mavic 3 Multispectral.

Best suited for:
- Pasture condition analysis.
- Vegetation mapping.
- Feed-area monitoring.
- Agricultural environmental intelligence.

Priority: 2.

## Recommendation C: Agricultural Multirotor / Heavy Payload

Reference model: DJI Agras T50.

Best suited for:
- Agricultural operation data integration.
- Spraying and spreading activity documentation.
- Pasture management activity records.

Priority: 3 - Optional.

This is not a primary animal monitoring platform.

## Recommendation D: VTOL Fixed-Wing

Reference model: Quantum Systems Trinity F90+.

Best suited for:
- Large-area surveys.
- Extensive farm mapping.
- Remote pasture monitoring.
- Regional geospatial intelligence.

Priority: 2.

## Selection Considerations

The recommendation should consider:
- Farm size and terrain.
- Animal species and density.
- Monitoring frequency.
- Required imagery and sensor types.
- Flight endurance and coverage.
- Operator availability.
- Data transfer and connectivity.
- Vendor support and integration access.
- Local aviation and privacy requirements.

Do not make a final hardware recommendation solely from farm size.
The mission, sensor and operator requirements must also be considered.

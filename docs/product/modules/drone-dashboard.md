# Drone Intelligence Dashboard

## Overview
- Registered drone devices.
- Integration status.
- Last data synchronisation.
- Latest imagery.
- Processing status.
- Monitoring coverage.

## Device Profile
- Vendor and model.
- Device identifier.
- Firmware and integration version.
- Sensor and camera configuration.
- Declared capabilities.
- Compatibility status.

## Aerial Monitoring
- Map and imagery viewer.
- Animal detection overlays.
- Herd counting summaries.
- Pasture imagery layers.
- Thermal imagery viewer where supported.

## Evidence Review
- Original media reference.
- Timestamp and location.
- AI observations.
- Reviewer decision.
- Related welfare observation or incident.

## Reporting
- Monitoring activity summaries.
- Aerial evidence records.
- Paddock and farm comparisons.
- AI review outcomes.
- Integration health reports.

## Access Control
Only authorised users may view sensitive imagery,
manage integrations or export evidence.
